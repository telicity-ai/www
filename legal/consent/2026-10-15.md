# Consent notice, version 2026-10-15

In effect from 2026-10-15 until a later version replaces it. Replaces
2026-10-12 (the heading, the folded notice and the two required checkboxes),
which the owner removed on 2026-10-15 because it made signing up feel heavy
for a temporary landing page.

Shown on https://telicity.ai/#waitlist (en) and https://telicity.ai/ko/#waitlist
(ko) as one printed line right under the sign-up button. There are no
checkboxes: entering an email address and pressing the button is the
consent this line describes. A sign-up record stores
consent_version = "2026-10-15".

The lines below are the page's text in reading order, as tools/legal.py reads
it. Never edit this file once it has been deployed. To change the wording,
add a new version file, change the form's consent_version on both pages, add
the id to consentVersions in api/_lib/copy.mjs, and run
python3 tools/legal.py --check.
